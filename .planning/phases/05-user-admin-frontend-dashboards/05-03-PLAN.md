## Objective
Build the Executive Admin Security Console with 4 KPI cards, live transaction monitor, audit log search explorer, high-risk user grid, visual Explainable AI (XAI) risk breakdown modal, and assemble the full application router in `App.tsx`.

## Proposed Changes

### 1. Visual XAI Modal
#### [NEW] [XAIModal.tsx](file:///c:/Users/hp/Documents/Projects/SecureFinTech/frontend/src/components/XAIModal.tsx)
- Header with Transaction ID, Reference, Timestamp, and Status Badge.
- Risk Score Gauge meter (0-100 score) and Risk Level Badge (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
- **60/40 Split Score Bar:** Rules Engine Score vs Scikit-Learn Anomaly Score.
- **Factor Attribution Cards:** Triggered rules and ML anomalies with factor name, severity, impact points, and human-readable explanation.
- Action Policy Banner (`APPROVE`, `FLAG`, `BLOCK`).

### 2. Executive Admin Console Component
#### [NEW] [AdminConsole.tsx](file:///c:/Users/hp/Documents/Projects/SecureFinTech/frontend/src/components/AdminConsole.tsx)
- **Top Security KPI Grid:** Total Volume ($), Blocked Fraud Count & Rate (%), Pending Review Queue, Security Events & Threat Intel Alerts Count.
- **Live Transactions & Review Queue:** View all transactions across all users; click any row to open the XAI Modal.
- **Audit Logs Explorer:** Searchable audit trail filtering by Category (`SECURITY_EVENT`, `ADMIN_ACTION`), Severity (`INFO`, `WARNING`, `CRITICAL`), Action, and Actor ID.
- **High-Risk User Detector:** List of user accounts flagged for elevated risk or blocked transfers.

### 3. Application Assembly
#### [NEW] [App.tsx](file:///c:/Users/hp/Documents/Projects/SecureFinTech/frontend/src/App.tsx)
- Main view router switching between Login, Signup, UserPortal, and AdminConsole based on AuthContext state and User Role (`USER` vs `ADMIN`).

#### [NEW] [main.tsx](file:///c:/Users/hp/Documents/Projects/SecureFinTech/frontend/src/main.tsx)
