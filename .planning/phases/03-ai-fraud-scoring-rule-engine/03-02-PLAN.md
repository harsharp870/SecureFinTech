# Plan 03-02: Scikit-Learn Anomaly Detector, Hybrid Aggregator & XAI Integration

**Phase:** 03 - AI Fraud Scoring & Rule Engine
**Plan:** 02 of 02
**Requirements:** FRAD-01, FRAD-02, FRAD-04, FRAD-05, FRAD-06

## Objective
Implement Scikit-Learn `IsolationForest` ML anomaly detector with synthetic startup baseline generator, hybrid 60/40 risk score aggregator with critical rule override, XAI feature attribution explanation generator, `AIFraudEvaluator` integration hook into payment execution, and XAI API endpoint.

## Proposed Changes

### ML Anomaly Detector (`backend/app/services/fraud_engine/ml_detector.py`)
- Implement `MLAnomalyDetector` class:
  - Startup model initialization: Check if `backend/app/ml/models/isolation_forest.joblib` exists; if missing, auto-generate 2,000 synthetic transaction vectors (95% normal, 5% anomalous) and train `IsolationForest(n_estimators=100, contamination=0.05)`. Save via `joblib.dump`.
  - `predict_risk_score(feature_vector) -> float`: Normalize raw `score_samples()` output to 0–100 risk score range.

### Hybrid Aggregator & XAI Generator (`backend/app/services/fraud_engine/hybrid_aggregator.py`)
- Combine rules score (60%) and ML score (40%). Apply critical rule override (forces score to >= 85).
- Map final risk score to risk level (`LOW`: 0-29, `MEDIUM`: 30-59, `HIGH`: 60-84, `CRITICAL`: 85-100) and action (`APPROVE`, `FLAG`, `BLOCK`).
- Generate structured XAI `risk_factors` JSON array with human-readable descriptions.

### FraudEvaluator Hook Integration (`backend/app/services/fraud_evaluator.py`)
- Implement `AIFraudEvaluator` implementing `BaseFraudEvaluator`.
- Update `default_fraud_evaluator` in `fraud_evaluator.py` to use `AIFraudEvaluator`.

### Payment Model & XAI API Endpoint
- Update `Transaction` model in `backend/app/models/payment.py` to include `risk_factors` (JSON column or text) and `risk_level`.
- Add `GET /api/v1/payments/{transaction_id}/xai` endpoint in `backend/app/api/v1/payments.py` returning detailed XAI risk breakdown.

## Verification Plan

### Automated Tests
- Create `backend/tests/test_fraud_engine.py` testing:
  - Model startup initialization and synthetic training.
  - Normal vs anomalous transaction risk scoring.
  - 4-tier risk level classification and action mapping (`APPROVE`, `FLAG`, `BLOCK`).
  - End-to-end payment transfer blocking on $12,000 transaction.
  - `GET /api/v1/payments/{id}/xai` endpoint response.
