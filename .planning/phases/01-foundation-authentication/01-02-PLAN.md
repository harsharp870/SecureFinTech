# Plan 01-02: Authentication API Endpoints, RBAC & Account Lockout

## Goal
Deliver end-to-end authentication features: signup, login, JWT token refresh, current user profile lookup, role-based access control (RBAC) middleware dependencies, and account lockout / rate limiting protections against brute-force login attempts.

## User Story
As a user or administrator, I want to register and securely log in to receive access tokens, with my account protected against brute-force attacks and unauthorized access.

## Tasks

<task>
<task_id>01-02-01</task_id>
<name>Implement Pydantic Request/Response Schemas</name>
<intent>Define data schemas for user registration, authentication credentials, tokens, and user profiles.</intent>
<action>
1. Create `backend/app/schemas/auth.py`:
   - `UserRegister`: `email` (EmailStr), `password` (min_length=8), `full_name`, `role` (default: USER).
   - `UserLogin`: `email` (EmailStr), `password`.
   - `Token`: `access_token`, `refresh_token`, `token_type` (default: bearer).
   - `TokenPayload`: `sub`, `role`, `exp`.
2. Create `backend/app/schemas/user.py`:
   - `UserResponse`: `id`, `email`, `full_name`, `role`, `is_active`, `is_locked`, `created_at`.
</action>

<task_id>01-02-02</task_id>
<name>Implement Auth Dependencies & RBAC Guards</name>
<intent>Create FastAPI dependency functions for parsing JWT tokens and enforcing role permissions.</intent>
<action>
1. Create `backend/app/api/deps.py`:
   - `get_db()`: Database session generator.
   - `get_current_user(db, token)`: Extract JWT from OAuth2PasswordBearer header, decode token, load user from DB, ensure active & not locked.
   - `require_role(allowed_roles)`: Dependency factory returning a dependency that verifies `current_user.role in allowed_roles` or raises HTTP 403 Forbidden.
</action>

<task>
<task_id>01-02-03</task_id>
<name>Implement Auth Endpoints with Lockout & Rate Limiting</name>
<intent>Implement /api/v1/auth routes (signup, login, refresh, me) with failed login tracking and account lockout.</intent>
<action>
1. Create `backend/app/api/v1/auth.py`:
   - `POST /signup`: Verify email unassigned, hash password, create User record, return `UserResponse`.
   - `POST /login`: Check if account `is_locked` (if locked_until > now, return HTTP 423 Locked). Verify password. If invalid, log `LoginAttempt(successful=False)`, increment consecutive failures. If failures >= 5, set `is_locked=True`, `locked_until = now + 15m`. If valid, clear failed attempts, log `LoginAttempt(successful=True)`, return `Token`.
   - `POST /refresh`: Generate new access token using valid refresh token.
   - `GET /me`: Return current user profile (`UserResponse`).
2. Create `backend/app/api/v1/users.py`:
   - `GET /`: Admin-only endpoint listing all users (`require_role([UserRole.ADMIN])`).
3. Include router in `app/main.py`.
</action>
