# Plan 01-01: Backend Architecture, Database Schemas & Security Core

## Goal
Establish the backend foundation: FastAPI application boilerplate, PostgreSQL database connection, SQLAlchemy ORM models for Users and Login Attempts, Pydantic settings configuration, and low-level cryptographic security helpers (password hashing, JWT issuance/verification).

## User Story
As a developer/security engineer, I want a clean FastAPI project structure with PostgreSQL ORM models and JWT security primitives so that authentication endpoints can securely register and log in users.

<task_id>01-01-01</task_id>
<name>Setup FastAPI Project Structure & Configuration</name>
<intent>Create the modular directory layout, requirements.txt, and environment configuration parser.</intent>
<action>
1. Create `backend/` directory structure:
   - `backend/app/main.py`
   - `backend/app/core/config.py`
   - `backend/app/core/database.py`

2. Configure Pydantic `BaseSettings` in `app/core/config.py` to read `DATABASE_URL`, `JWT_SECRET_KEY`, `JWT_ALGORITHM`, `ACCESS_TOKEN_EXPIRE_MINUTES`, and `REFRESH_TOKEN_EXPIRE_DAYS`.
3. Set up SQLAlchemy async engine and sessionmaker in `app/core/database.py`.
</action>

<task_id>01-01-02</task_id>
<name>Implement User and LoginAttempt ORM Models</name>
<intent>Define SQLAlchemy models for user credentials, roles, and failed login attempt tracking.</intent>
<action>
1. Create `backend/app/models/base.py` with SQLAlchemy Base.
2. Create `backend/app/models/user.py`:
   - `User`: `id` (UUID), `email` (unique, indexed), `hashed_password` (string), `full_name`, `role` (Enum: USER, ADMIN), `is_active` (bool), `is_locked` (bool), `locked_until` (datetime, nullable), `created_at`, `updated_at`.
3. Create `backend/app/models/login_attempt.py`:
   - `LoginAttempt`: `id`, `email`, `ip_address`, `successful` (bool), `failure_reason` (string, nullable), `timestamp` (datetime).
</action>

<task>
<task_id>01-01-03</task_id>
<name>Implement Security Primitives (Password Hashing & JWT Utils)</name>
<intent>Create secure cryptographic helpers for password hashing (Argon2/Bcrypt) and JWT token generation/decoding.</intent>
<action>
1. Create `backend/app/core/security.py`:
   - `get_password_hash(password: str) -> str`: Hash password using `passlib.context.CryptContext(schemes=["argon2", "bcrypt"])`.
   - `verify_password(plain_password: str, hashed_password: str) -> bool`.
   - `create_access_token(subject: str, role: str, expires_delta: timedelta = None) -> str`.
   - `create_refresh_token(subject: str, expires_delta: timedelta = None) -> str`.
   - `decode_token(token: str) -> dict`.
</action>
<files_to_modify>
- [NEW] backend/app/core/security.py
</files_to_modify>

</verification>
</task>
