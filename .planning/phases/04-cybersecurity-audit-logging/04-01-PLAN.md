## Objective
Implement the immutable `AuditLog` database model, audit logging service helpers for recording security events and admin actions, and FastAPI middleware for OWASP security headers.

## Proposed Changes

### 1. Database Schema
#### [NEW] [audit.py](file:///c:/Users/hp/Documents/Projects/SecureFinTech/backend/app/models/audit.py)
- Create `AuditLog` SQLAlchemy model:
  - `id`: `String(36)`, Primary Key
  - `category`: `String(50)`, index (`SECURITY_EVENT`, `ADMIN_ACTION`, `SYSTEM_ALERT`)
  - `severity`: `String(20)`, index (`INFO`, `WARNING`, `CRITICAL`)
  - `action`: `String(100)`, index
  - `actor_id`: `String(36)`, ForeignKey to `users.id`, nullable
  - `ip_address`: `String(45)`, index
  - `user_agent`: `String(255)`, nullable
  - `details`: `Text`, nullable (JSON payload)
  - `created_at`: `DateTime(timezone=True)`, index
